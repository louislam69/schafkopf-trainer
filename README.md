# Schafkopf-Trainer

Schafkopf gegen drei Bots — Sauspiel, Wenz, Farbsolo und Farbwenz, dazu
Spritze, Retour und Tout. Nach jedem Blatt wird besprochen, welche Züge
Augen gekostet haben und warum.

Spielen: https://louislam69.github.io/schafkopf-trainer/

Reines HTML, CSS und ES-Module — kein Build, keine Abhängigkeiten.
